# 五星象棋

五星象棋是一款中国象棋练习与对弈软件。

## 主要功能

### 棋谱

- 浏览和管理内置 `books` 目录下的棋谱文件，目前支持 PGN、XQF 格式。
- 支持指定外部棋谱仓库目录，用同一套管理界面浏览外部棋谱。
- 棋谱支持多分支树结构，可在分支间自由跳转、排序，并支持多棋谱合并。

### 残局练习

- 内置残局题库，逐局挑战，完成进度自动记录。

### 打谱与复盘

- 主要功能基本都是这个页面改装的。
- 「背谱」模式下隐藏未完成分支，辅助记忆。

### 对弈
垃圾

## 个性化

- 棋子与棋盘支持经典绘制，也可使用内置或自行导入的图片样式，棋盘摆放棋子位置偏差太大可以进行位置校准。
- 按钮工具条可自由增删、排序。
- 界面设置可恢复默认，数据可一键备份为 zip 或从备份恢复。

## 便捷操作
- 打谱界面棋盘上下滑动可以在棋谱中前进后退。
- 分支选择时可以点击棋盘上的标签选择分支。

## 浮动五星
打谱页面中有三个星，提供一些额外功能  
**不想使用浮动五星功能， 可以在设置中关闭。**
- 绿星：切换下方面板的显示状态，在隐藏标题/隐藏面板/全部显示之间切换。
- 红星：点击打开自定义操作菜单。长按可以设置菜单项目。跟下方工具条功能类似。
- 黄星：拖动调整棋盘的大小。 长按可以禁用/打开。

**打谱页面横屏操作 bug 更多，容易导致界面卡死。重启在界面设置中恢复默认设置可能有帮助。**
